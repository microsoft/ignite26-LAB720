# Attendee instructions

| Track | Time | Instructions |
|---|---:|---|
| Modernize application code with GitHub Copilot | 50 minutes | [modernize-app-code.md](modernize-app-code.md) |
| Review the public final checkpoint (no starting archive) | Self-paced | [review-final.md](review-final.md) |

Use the full modernization guide for assessment, rulebook-guided planning, execution and validation of the prepared results. Its [self-serve setup](../README.md#full-lab-setup) is a preview: the original workload archive is not included and still needs an approved distribution source. If you only have a clone, choose the final-checkpoint review: trace the published findings to the final code and optionally run the gateway tests with one command. It does not run the agent or recreate the missing exercises.

The SRE Agent guide is not part of this self-serve modernization track.
